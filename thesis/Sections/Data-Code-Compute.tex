\section*{Data, code and compute}
\addcontentsline{toc}{section}{Data, code and compute}

Tahoe-100M is a publicly released single-cell perturbation atlas; no new biological data were
generated for this thesis. The analysis code, training and evaluation job scripts, and result
artifacts supporting the reported tables and figures are retained in the associated project
repository. Model training, generation, and the computationally intensive evaluation stages were
run on Bocconi University's high-performance computing infrastructure.
